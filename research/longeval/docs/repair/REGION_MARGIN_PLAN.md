# Exploratory regional repair feasibility gate — 2026-11-18

Freeze this gate before computing its results. It is a cheap falsification test,
not a claim that geometric repair is new and not a replacement for recall tests.

The previous witness rule added shortcuts useful to single fitting queries. A
possible next rule would favor edges whose direction of improvement survives
query perturbations, instead of ranking edges only by their generating query.
For inner product, let w = destination - source and let c be a fitting query.
For every q with ||q-c|| <= r, Cauchy–Schwarz gives

    q · w >= c · w - r ||w||.

A positive lower bound certifies that the destination scores above the source
throughout that ball. This is an elementary sufficient condition; it neither
certifies top-k membership nor proves that a beam search reaches either endpoint.
Failure of the bound does not prove absence of actual transfer. It can be very
conservative in high-dimensional normalized embedding spaces.

Use the frozen disjoint protocol's three 30-query fitting sets. For each previously
recorded witness edge generated by one of those fitting queries, set r to the
distance from its generating query to the nearest *other fitting query*. This
radius is set from fitting vectors only. The gate asks whether any such edge has
a strictly positive robust margin at that radius (numerical margin 1e-12).
No tuning or development vector, reference or retrieval outcome enters the gate.
Proposal generation was independently per query in the earlier screen; this
audit filters the recorded proposal pool by the new fitting IDs. It does not
rerun the earlier global 32-edge selection as though it were fitted to 30 queries.

If every edge fails in every split, do not implement or submit this isotropic-ball
rule. Preserve the result as evidence that this particular certificate is too
conservative for the present proposals, not evidence that all regional repair
fails. If some pass, a new frozen candidate experiment must compare against the
unfiltered proposals, NGFix, reverse-edge controls, equal-work wider search, and
an equal-memory graph before any promotion. Include fitting and adjacency costs.

Prior-art constraints checked from primary sources on 2026-11-18:

- [NGFix/RFix](https://arxiv.org/html/2510.22316v1) already repairs query-local
  connectivity and routes; it also supports approximate neighbor references.
  Approximate references alone are not a new method.
- [RoarGraph](https://arxiv.org/html/2408.08933v1) already uses historical queries
  to guide graph construction through bipartite projection and connectivity
  enhancement. Query-guided edge selection alone is insufficient differentiation.
- [Alpha-convergent graphs, v5](https://arxiv.org/abs/2510.05975v5) propose a
  shifted/scaled triangle-inequality pruning rule with convergence guarantees and
  a practical local variant. A geometric guarantee alone is not a novelty claim.
- [Delta-EMG, v1](https://arxiv.org/abs/2511.16921v1) studies error-bounded graph
  search for arbitrary queries. Error bounds and recall bounds must be distinguished.

The last two sources were checked at abstract level here; an algorithm-level
comparison is still required if this direction survives. No exhaustive novelty
search or distinction from these methods has been established.
